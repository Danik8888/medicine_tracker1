# Трекер приёма лекарств

Учебный проект: мобильное приложение, в котором можно завести курс приёма лекарств и отмечать, что принял. Клиент — React Native (Expo), сервер — Spring Boot, база — PostgreSQL.

Репозиторий разбит на две части:

- `medicine_tracker-main` — приложение
- `medicine_tracker_backend-main` — серверная часть

## Сервер

Spring Boot 3, Java 21, PostgreSQL, авторизация по JWT (ключ лежит в `keys/keystore.jks`).

Логин и пароль от базы прописаны в `src/main/resources/application.properties`, там же комментариями помечено, что можно трогать, а что нет. База называется `MedicineTracker`, порт — 7634.

Запуск:

```
cd medicine_tracker_backend-main
./mvnw spring-boot:run
```

Контроллеры: `/courses` — курсы приёма, `/medicaments` — справочник лекарств, `/takeMedicine` — отметки о приёме.

## Приложение

Expo / React Native, экраны лежат в папке `app`. Есть вход и регистрация, расписание, список активных и завершённых курсов, добавление курса (обычный, на неделю, с периодом), справочник лекарств. У админа отдельные вкладки для работы со справочником.

Запуск:

```
cd medicine_tracker-main
npm install
npx expo start
```

Адрес сервера зашит в `constants/constants.js` — сейчас там локальный IP `192.168.0.102:7634`. Если сервер запущен на другой машине или в эмуляторе, этот адрес надо поменять.
